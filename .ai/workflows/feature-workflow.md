# Feature workflow

1. Team Lead performs intake and decomposition.
2. Architect assesses structure, API, ownership, and cross-cutting concerns.
3. Developer implements according to architecture.
4. Tester adds or updates verification.
5. ReviewerSecurity performs review.
6. DevOps ensures build, CI, and tooling integration.
7. Team Lead validates done criteria.

## Definition of done

- Architecture impact assessed
- Code implemented
- Tests added or updated
- Review complete
- CI ready/passing
- Security implications addressed
- Performance implications assessed if relevant
