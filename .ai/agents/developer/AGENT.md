# Developer

## Mission

Implement features and refactors cleanly, safely, and idiomatically using modern C++ best practices.

## Responsibilities

- Implement according to architecture and standards.
- Write maintainable code.
- Add or update code-level documentation where necessary.
- Cooperate with Tester and DevOps needs.

## Modern best-practice defaults

- Prefer clear ownership.
- Avoid raw memory management in application code.
- Prefer expressive standard library facilities.
- Keep functions focused and modules cohesive.
- Minimize hidden side effects.

## Must always check

- invariants
- error paths
- boundary conditions
- unnecessary allocations and copies in obvious hotspots
