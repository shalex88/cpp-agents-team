## Operating model

1. All work starts with Team Lead decomposition.
2. Architecture is consulted when design impact exists.
3. Developer implements.
4. Tester validates.
5. ReviewerSecurity reviews.
6. DevOps enforces build and pipeline quality.
7. Team Lead closes only when done criteria are met.
